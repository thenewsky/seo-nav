当前特征 → 本轮练习 → 目标与能力

练习现在你的特征本轮做什么 / 先放什么目标补齐的能力点本轮证据和产出物
第一站
练上线与收录		能做出网页，但还没独立走通域名、部署、统计和收录检查。本轮做：做可用小工具，跑通上线和索引检查；功能卡住可先用完整静态示例练流程。

先放：复杂支付、多语言、批量内页、大词排名及流量收入目标。

独立域名与页面可用，统计正确，首页已索引；曝光和点击留到下一轮。连接域名与部署；识别测试访问；区分提交、抓取、索引与曝光；排查未索引原因。网站地址、代码仓库、部署记录、功能与统计测试、GSC 索引检查结果。
第二站
练出词与点击		已会上线与查索引，但还不会判断竞争、读查询或获得相关外链。本轮做：逐词看搜索结果、改页面，做相关外链实践并观察搜索反馈。

先放：高竞争大词、批量扩页、复杂支付和垃圾外链。

页面出现相关查询与曝光，并逐步获得相关搜索点击。判断意图与竞争、识别搜索占位；优化页面；核查相关外链；比较查询、排名、曝光与点击。查询与搜索结果对比、页面更新记录、外链来源与目标页清单、GSC 前后数据。
第三站
练内页扩展		已会读查询与点击，但还没独立做过同主题内页扩展与逐页复盘。本轮做：围绕首页同主题拆内页、做内链，继续相关外链实践并逐页核查。

先放：仅换词的批量页面、一次铺满多语言。

同主题内页可用且已索引，出现相关查询与曝光，据逐页反馈决定扩展。同主题词页匹配与站点边界；制作内页和内链；持续外链实践；逐页诊断与复盘。需求与页面清单、内页地址、内链结构、内外链记录、逐页搜索数据和复盘结论。
后续经营
练用户与经营		准备做正式 SaaS 工具站，还不清楚用户为何使用、复访或订阅；可并行开始。本轮做：观察核心任务与复访，验证价格和免费额度，按需接入最小账号与试付。

先放：未验证就搭完整账号支付系统、堆无关功能或大规模买量。

有使用与试付反馈，算清免费/付费任务成本，结合复访和毛利判断下一步。定义复访口径；验证试付与额度；按需引入身份与计费；区分免费/付费任务及持续成本。场景卡、任务/复访观察、价格与额度测试、单位与持续成本表、下一步决定。

会用 AI 写代码、买了域名或提交了站点地图，都不能代替这张表的完成证据。证据与产出物由你在站外人工准备；每轮按需查手册，正式产品的需求验证可并行开始。
