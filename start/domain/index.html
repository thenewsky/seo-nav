命名、域名与基础设置		 本阶段目标

确定一个可用名称和首站访问地址方案。

 最小路线

练手可先用部署平台提供的地址；需要自有域名时，比较注册与续费条件，检查名称及域名历史，购买后保留解析配置给部署阶段使用。

 完成标准

保存名称、域名候选、注册及续费信息与账号归属，或明确先使用平台地址。

 这一阶段

先让名称清楚、资产可管理，再决定是否购买域名。
操作步骤01 · 挑选少量名称做什么

列出两三个容易拼写、与用途相关的名字，搜索同名产品，避开明显借用他人品牌的命名。

完成判据

能读、能拼、能解释用途，并记录同名检查结果。

常见卡点

可注册不代表没有名称或品牌冲突，拿不准就换一个。

02 · 判断是否立即买域名做什么

先选平台地址或自有域名；购买前在注册商核对注册、续费、转移、退款与自动续费条件。

完成判据

有明确决定与预算，知道第二年的续费安排。

常见卡点

不要只看首年优惠，也不要把二手域名购买误认为普通注册。

03 · 检查域名历史做什么

用域名查询与网页历史查看注册状态、旧用途和明显异常记录，保存结果。

完成判据

记录候选域名的查询时间、旧用途与仍不确定的事项。

常见卡点

历史为空不等于安全保证，发现明显不相关或异常用途可换候选。

04 · 建立资产清单做什么

记录注册商、域名、到期日、部署账号与恢复方式；为重要账号启用可用的安全验证。

完成判据

能够找到谁管理、在哪里续费、如何恢复账号。

常见卡点

密码和恢复码放密码管理器，不要写进公开仓库或网页。

05 · 准备解析做什么

先读部署平台绑定域名要求；需要改 DNS 时记下原记录，逐项添加并等待验证。

完成判据

知道要修改哪一条记录，且有原配置可恢复。

常见卡点

不要反复切换域名服务商或同时更改多项记录，邮件记录尤其要保留。
