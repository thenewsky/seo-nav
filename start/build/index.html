操作步骤

步骤做什么完成判据常见卡点
01 · 写给 AI 的任务说明提供需求卡、三组例子与页面结构，要求先做输入、处理、结果，说明首版不需要的功能。生成结果与预期一致，功能边界没有被扩成完整 SaaS。没有验收例子时，AI 容易补出看起来完整但不能用的页面。
02 · 建立代码与本地预览把源文件放进独立项目，请 AI 给出适合本机的预览命令及停止、重启方法；打开返回的 localhost 地址，每次只修改一个可检查的点。本地地址能打开，知道停止和重启预览的方法。不要直接双击文件后就假定部署也能正常；资源路径要用实际预览核对。
03 · 做英文主页面首屏展示输入与操作；下方用自己的文字写用途、操作步骤、示例、限制与常见问题。第一次来的用户能知道输入什么、结果有什么用。不要复制对标站文案、会员正文或品牌素材；工具与介绍必须一致。
04 · 验收功能边界逐项跑正常、空白、异常与较大输入，检查错误提示、复制或下载结果及重复操作。每项都有可观察结果，失败时用户知道如何修正。按钮有动画不等于功能有效，不能只测试一个演示样本。
05 · 检查手机与私密信息用窄屏检查表单、结果和长文本；检查仓库里是否有密钥、密码、个人文件。手机能完成任务，公开文件不含秘密，必要的 API 在服务端调用。静态网页里的密钥会被访问者读取；这类功能要转到支持后端的平台。
