# 上站能力练习路线（探索性改版）

## 用户行为与本轮目标

网站第一位使用者已多次反馈：内页应能一屏看完，风格保留各专题特点；当前通用流程不能说明第一站与后续打磨分别练什么。用户记得 Agent 对话中的三站区分，希望知道自己当前能力与适合的练习。本轮按其授权做可反馈的探索性改版；第一位用户的使用问题是证据，原型完成不代表市场需求成立。

## 设计决定

入口 `/start/` 改为能力分层，而不是让零基础使用者一次执行通用八环节。四条路线分别是 `/start/first-site/`、`ranking/`、`expansion/`、`product/`。四层是本站整理：前三层吸收练流程、排名反馈、内页扩展的练手思路，经营层明确为补充，不称为原作者统一版本。

| 本轮目标 | 进阶前的动作证据 | 本轮暂缓 |
|---|---|---|
| 上线与收录 | 可用功能、独立域名、统计事件、GSC 实际已索引结果 | 大词、批量内页、付费登录 |
| 出词与点击 | 能读查询与曝光、记录一次改动并观察相关搜索点击 | 批量扩页、统一排名硬门槛 |
| 内页扩展 | 新页独立可用且已索引，有相关查询/曝光，能逐页复盘 | 换词批量复制与一次铺满多语言 |
| 用户与经营 | 实际使用、复访或变现证据，结合反馈与成本作决定 | 未验证需求就搭完整支付账号系统 |

不会凭做过多少站或会不会 AI 编程自动判定阶段。可以在已有站上补练。准备正式产品时需求验证可并行进行，练手站的技术验证不能替代商业需求验证。搜索量、DR、外链数量、等待天数与收入都不设置统一硬门槛。

八个原环节 URL 保留，在 `/start/workflow/` 聚合为通用手册。练习页只链接这轮相关环节，手册页标明按需查阅。主站与翻石地图样式和内容延续此前已确认版本。

## 最小反馈验证

用户能在总览找到自己的能力缺口，选定一轮练习，说出本轮暂缓项与需保存的证据；完成练习时能按证据而非工具数量判断下一步。若仍需助手解释如何选路线，继续改入口文案；若共同目标没有真实使用，记录为待验证，而非扩建完整学习系统。

## 验收

两个生成器 `--check`、相对链接和资源完整性校验；用 ego-browser 验证 14 个路线页与翻石地图在 1280×800、1366×768 下无纵向和整页横向溢出。手机允许正常纵向阅读和表格横向阅读，保持完整内容与页内定位。新增数据与模板均为静态内容，禁用 JS 仍可读取。
