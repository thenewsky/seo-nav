# 主站与专题风格统一

用户反馈：上站路线及阶段页与主站风格不一致，要求重新改造。

方向：以主站为视觉基准，保留系统字体、S 计划品牌页头及口号、灰色背景、蓝色左侧分类、四列白色内容和原有链接交互。上站路线、八个阶段与翻石地图使用同一套结构。

- 各页使用主站的 16px 入口和分类字号，补充说明统一为 13px 灰字。
- 移除内页灰色横向表头、段落式开场和分散的多个表格；导航、路线说明、步骤、工具、原文出处与前后阶段放入分类表格。
- 专题导航保持四列，并标出当前栏目；页面名称保留在主内容标题、左侧分类及浏览器标题中。
- 新增 `assets/topic.css` 作为专题共用的少量补充样式；基础外观继续继承 `assets/navigation.css`，不修改首页。
- 不修改阶段数据、工具地址及原文引用。翻石地图保留 28 个入口、六分类、阅读起点和彼得·林奇引文。
- 在现有开发分支上提交；保持原日期备份，不发布线上。

验收：两个生成器的只读检查、语法与 diff 检查；全部页面相对链接、资源、四列结构；浏览器对照首页和专题的字号、页头、分类色、链接样式，检查桌面与窄屏显示及阶段跳转。

验收结果：两个生成检查、Node 语法、diff 检查通过；11 个页面的本地路径和每行四个内容单元格通过，首页及两个内容 JSON 与修改前完全一致。浏览器确认专题入口/分类为 16px、分类色与主站一致；390px 窄屏正文无横向溢出，表格可用键盘横向滚动，路线到阶段的跳转通过。
