# 内页首屏密度优化

用户要求所有内页尽量一屏看完，减少自行翻页。保留第三版的独立标题、蓝色分区及原有内容。

## 实现

- 内页单独加载 `assets/compact.css`，缩小页头和外部留白；首页不加载、不改动。
- 路线总览减小表格 padding 和行距，保留两阶段分组。
- 阶段页顶部并排展示目标、最小路线和完成标准；主体左侧步骤表，右侧工具和引用，减少纵向叠加。
- 4 个工具在侧栏排列成 2×2；原文标题与作者、平台、日期合并展示，保留全部原链接。
- 翻石地图只收紧字体尺寸、间距和说明行距，保留原标题、引文、返回导航、6 分类及 28 条目。
- 小屏保持可读性，自适应顺排；增加步骤、工具、原文快捷定位。页面不使用整页缩放、文本截断、隐藏正文或固定高度裁切。
- 内容 JSON 和主站 HTML、共享基础 CSS 均保持不变。

## 验收

ego-lite 检查总览、8 个阶段页和翻石地图。1280×800 与 1366×768 下，10 个内页的文档高度均等于视口高度，页面无纵向溢出；路线和阶段页主体底部约在 573–719px。390px 小屏正文宽度保持 390px，页内原文快捷定位通过。

11 个页面的站内链接、静态资源与锚点检查通过。37 个步骤的动作、判据和卡点，32 个工具与 18 条引用全部保留；首页及原始内容数据与本次修改前一致。两个生成器的 --check、Node 语法及 diff 检查通过。

在原开发分支提交并推送，不发布线上。本地预览使用 `?v=compact4` 以避开上一版缓存。
